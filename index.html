Build paths

Start with the engine. Shape the build around the goal.

Every project depends on its platform, condition, intended use, and parts combination. The first step is getting those details in one place so the scope can be reviewed clearly.

01 / REBUILD

Rebuilds & refreshes

Share what failed, what is worn, and what you want to reuse. The inquiry helps define the inspection, parts, and assembly questions to resolve.

02 / PERFORMANCE

Performance combinations

Describe the engine platform, fuel, intended use, target, and parts already selected. Build choices should match the whole combination.

03 / CUSTOM

Custom engine projects

Bring a swap, unusual platform, or one-off plan. Include the exact engine code and constraints so the project can be assessed on its own merits.

What to include

A useful inquiry starts with a few real specs.

You do not need a finished parts list. Send what you know; the missing details can be identified during the written review.

Engine & condition

Make, engine code, displacement, current condition, and any measurements or known failures.

Use & target

Daily street, track, drag, restoration, or another use; include the power or reliability goal if you have one.

Parts & constraints

Parts already purchased, parts you still need, fuel, transmission, budget range, and timing.

Location & logistics

Your city and state, where the engine is now, and whether shipping or local handoff is part of the plan.

Project process

Clear scope before parts or assembly.

Engine details are reviewed by email. Parts, machining, assembly steps, timing, payment terms, and any testing are defined in the written project scope before work begins.

This site is for project inquiries. It does not accept deposits, parts shipments, or engine drop-offs.

01Send the engine details. Identify the platform, condition, use, and goal.
02Review the combination. Confirm unknowns, parts, constraints, and project fit.
03Agree on scope in writing. Document deliverables, parts responsibility, timeline, and terms.
04Start after approval. Work begins only after the written scope is accepted.
FAQ

Engine build questions.

Do you only build BMW engines?

No. Engine projects are not limited to BMW. Send the make, engine code, and what you want the build to do.

Do I need to know every part I need?

No. Include the parts you have and the goal you are working toward. The written review can identify what still needs to be confirmed.

Can you guarantee a specific horsepower number?

No number is promised from an engine build alone. Results depend on the full combination, fuel, tuning, installation, and operating conditions.

Do I have to call?

No. Start by email with the inquiry form. Add photos, measurements, or a parts list to the message before you send it.
